# Бот-расписание для колледжа

Telegram-бот, который каждый день присылает расписание пар:
- **вечером** — на завтра (время выбирает сам пользователь/чат);
- **утром** — на сегодня (время тоже своё).

Поддерживает:
- **автоматическую загрузку расписания с сайта Самарского ГАУ (ssaa.ru)** —
  выбираешь форму обучения, курс и группу, всё остальное бот делает сам и
  обновляет расписание каждые 6 часов;
- **подгруппы** — можно выбрать свою, тогда приходят только твои пары;
- несколько учебных групп с разными расписаниями;
- **семестры** — у каждого периода обучения (например "Осень 2026" и
  "Весна 2027") своё расписание, бот сам определяет, какой семестр сейчас идёт;
- **чередование недель** (1-я/2-я, "числитель/знаменатель") внутри семестра;
- работу как **в личных чатах** (у каждого своё время рассылки), так и
  **в групповых чатах** (одна рассылка на весь чат, настраивают только
  администраторы чата);
- заполнение расписания либо вручную по шаблону, либо через готовый промпт
  для внешней нейросети (Claude, ChatGPT и т.п.) по скриншоту;
- админ-панель для редактирования текстов, которые пишет бот.

---

## 0. Что умеет бот (интерфейс)

- **Один экран вместо ленты сообщений.** Кнопки редактируют то же сообщение,
  команды и введённый текст (дата, фамилия, время) бот удаляет, новая
  рассылка заменяет предыдущую. На каждом экране — «⬅️ Назад».
- **Три закреплённые кнопки внизу:** 📅 Сегодня · 🌙 Завтра · 🗓 Неделя
  (ставятся по /start, держится одно служебное сообщение).
- **📅 День** с листанием ◀️ ▶️, **🗓 неделя** с датами, **📆 календарь** —
  сетка месяца из кнопок, точкой • отмечены дни с парами.
- **☕ Окна** между парами помечаются (по сетке звонков ssaa.ru: пропущенный
  номер пары), в итоге дня — «4 пары · 08:00 – 15:30 · ☕ 1 окно».
- **👤 Преподаватели**: выбор по букве или фамилией в чат → его пары по всем
  группам на любую дату (листание и календарь), «🟢 идёт сейчас».
  Чтобы список был полным, `api/tick.js` в фоне подгружает все группы
  колледжа (`SSAA_PRELOAD_FORMS`, по умолчанию `11,13`).
- **⚙️ Настройки**: группа (только с сайта), подгруппа, время рассылок
  кнопками-пресетами, часовой пояс.
- **💬 Поддержка**: контакт @temniy_prinz и/или сообщение боту — оно уходит всем `ADMIN_TELEGRAM_IDS`
  с меткой `#id…`; ответ реплаем на него бот перешлёт пользователю.
- **💝 Донат**: реквизиты меняются в `/admin` → «Донат».
- Можно просто написать в чат дату (`20.10`) или фамилию преподавателя.

Ручное создание групп и ввод расписания убраны из меню пользователя:
группы берутся только с сайта. Старые ручные группы продолжают работать,
удалить их можно в `/admin` → «Группы».

## 1. Как это устроено (архитектура)

```
Telegram  ──(webhook)──▶  /api/webhook.js  ──▶  lib/bot.js (grammy)
                                                     │
                                                     ▼
                                              Postgres (Neon/Supabase)
                              users / group_chats / groups / terms / lessons /
                              sent_log / group_chat_sent_log / bot_texts

cron-job.org (раз в минуту) ──▶ /api/tick.js ──▶ проверяет, у кого/какого
                                                  чата сейчас наступило время
                                                  рассылки, шлёт sendMessage
                                                  напрямую в Telegram API
```

**Почему так:** Vercel — serverless, там нет вечно работающего процесса,
поэтому нельзя использовать обычный long-polling бота и обычный
`setInterval`. Вместо этого:
- Telegram сам стучится в наш `/api/webhook` при каждом сообщении (push, а не pull).
- Рассылку по расписанию дёргает **внешний** бесплатный крон-сервис
  (cron-job.org или EasyCron) раз в минуту — он просто делает HTTP-запрос
  на `/api/tick`, который сравнивает текущее время каждого подписчика
  (личного пользователя или группового чата, с учётом их часового пояса)
  с их настройками.

Хватит ли Vercel — да, с большим запасом (бесплатного Hobby-плана).
Единственное, что Vercel не умеет "из коробки" на бесплатном плане —
поминутный cron, поэтому и используем внешний сервис-будильник.

### Структура файлов

```
api/
  webhook.js       — принимает апдейты от Telegram
  tick.js          — раз в минуту проверяет и шлёт рассылки (личка + группы)
lib/
  bot.js           — вся логика бота (меню, диалоги, личка и группы)
  ssaa.js          — загрузка и разбор расписания с сайта ssaa.ru
  ssaaSync.js      — сохранение расписания с сайта в базу + автообновление
  schedule.js      — группы/семестры/расписание + парсер текста + промпт для ИИ
  digest.js        — общая логика "расписание на сегодня/завтра" (кнопки и рассылка)
  format.js        — красивое оформление сообщений (эмодзи, HTML, недели)
  time.js          — часовые пояса, парсинг дат, расчёт недели 1/2
  texts.js         — редактируемые через /admin тексты бота
  db.js            — подключение к Postgres
migrations/
  001_init.sql        — базовая схема (users, groups, lessons, sent_log)
  002_bot_texts.sql    — таблица bot_texts (админ-панель)
  003_toggle_times.sql — поля для мгновенного вкл/выкл рассылки
  004_terms.sql        — семестры + чередование недель
  005_group_chats.sql  — поддержка групповых чатов
  006_ssaa_import.sql  — расписание с сайта, подгруппы, точные даты пар
test/              — автотесты (npm test) на сохранённых ответах сайта
scripts/
  migrate.js       — применить все миграции к базе (по порядку)
  set-webhook.js   — зарегистрировать вебхук в Telegram
```

## 2. Как пользователь заполняет расписание

### Самый простой способ — с сайта ssaa.ru

`/start` → «👥 Учебная группа» → «🌐 Выбрать группу с сайта ssaa.ru» →
форма обучения → курс → группа → подгруппа. Всё: семестр и все пары
загружаются сами, вводить ничего не нужно.

Как это работает (`lib/ssaa.js`, `lib/ssaaSync.js`):
- список групп и семестров бот берёт со страницы
  `https://ssaa.ru/raspisanie-ochnoe`, расписание группы — запросом к
  `https://ssaa.ru/01/shedule.php` (тот же, что делает форма на сайте);
- у каждой пары сохраняются **точные даты** с сайта, поэтому праздники и
  сдвиги учитываются сами, а неделя 1/2 совпадает с сайтом;
- записи подгрупп (`Предмет/-`, `-/Предмет`, кабинет `А1/А2`,
  преподаватели через запятую) раскладываются по подгруппам — у каждой
  свой кабинет и свой преподаватель;
- перед показом или рассылкой бот проверяет, не устарели ли данные
  (по умолчанию 6 часов, переменная `SSAA_SYNC_HOURS`), и при
  необходимости тихо обновляет. Если сайт не отвечает — показывается
  последнее сохранённое расписание, ошибка видна в меню группы;
- кнопка «🔄 Обновить с сайта» — обновить прямо сейчас.

### Вручную (для расписаний, которых нет на сайте)

1. `/start` → «👥 Учебная группа» → «➕ Создать вручную».
2. Меню «📅 Расписание» → «📆 Семестры» → «➕ Добавить семестр»: название
   (например "Осень 2026"), дата начала и дата окончания.
3. Дальше — «✏️ Заполнить/изменить расписание» → выбрать семестр → один из
   двух способов:
   - **🤖 Промпт для нейросети** — бот присылает готовый текст-инструкцию;
     его нужно скопировать и отправить вместе со скриншотом расписания в
     любую нейросеть (Claude, ChatGPT и т.п.), а её ответ целиком прислать
     обратно боту — он сам разберёт и сохранит.
   - **✍️ Ввести вручную** — бот присылает шаблон, его заполняют глядя на
     скриншот самостоятельно.

Формат текста (что для промпта, что для ручного ввода) один и тот же:
```
ПН
08:30-10:00 Математика | ауд. 305 | Иванова А.И.

ПН1
10:10-11:40 Физика | ауд. 210

ПН2
10:10-11:40 Химия | ауд. 118

ВТ
08:30-10:00 История
```
`ПН` без цифры — пара каждую неделю. `ПН1`/`ПН2` — только на 1-й или 2-й
неделе (чередование). Аудитория и преподаватель — необязательны.

Расписание сохраняется **на весь семестр этой группы разом** — заполнить
нужно один раз, получают его все, кто на неё подписан (лично или через
групповой чат).

## 3. Время рассылки и кнопки

В меню «⏰ Время рассылок» настраивается время утренней/вечерней рассылки и
часовой пояс. Рядом со временем — переключатель 🟢/⚪: нажатие сразу
включает/выключает рассылку (сообщение обновляется на месте, без отправки
нового); при повторном включении подставляется то же время, что было раньше.

Внизу экрана (как обычная Telegram-клавиатура быстрых ответов, а не кнопки
под сообщением) всегда доступны **«📨 Расписание на сегодня»** и
**«📨 На завтра»** — присылают расписание сразу, не дожидаясь автоматической
рассылки. Команды `/today`, `/tomorrow` делают то же самое.

В меню «👥 Учебная группа» есть «🗑 Удалить группу» (с подтверждением) —
удаляет группу, все её семестры и расписание.

Все переходы по меню (кнопки-экраны, не разовые уведомления) удаляют
предыдущий экран и показывают новый — чтобы в чате не копились старые меню.
У каждого такого экрана есть кнопка «⬅️ Назад» или «❌ Отмена».

## 3.1. Поиск преподавателя

Кнопка **«🔎 Найти преподавателя»** (или команда `/teacher Фамилия`) ищет
сразу по **всем** учебным группам, у которых сейчас идёт семестр — не только
по той, что настроена в этом чате. Присылает: ведёт ли преподаватель пару
прямо сейчас (и в какой аудитории, для какой группы), и полный список его
пар на сегодня по всем группам.

Это работает по тому, что уже вписано в поле "аудитория" при заполнении
расписания — отдельного поля "корпус" в базе нет. Чтобы поиск показывал
корпус, указывайте его прямо в поле аудитории при заполнении расписания,
например: `2 корпус, ауд. 305`. Шаблон и промпт для нейросети (раздел 2) уже
подсказывают это.

## 4. Групповые чаты

Бота можно добавить в общий чат учебной группы — тогда расписание будет
приходить сразу всем в этот чат, а не каждому в личку по отдельности.

**Важная настройка перед этим (один раз):** у Telegram-ботов по умолчанию
включён "режим приватности" — в группах бот видит только команды (`/start`),
но не обычную переписку, которая нужна для диалогов настройки (название
группы, даты семестра, текст расписания). Отключи это:
1. Напиши `@BotFather` → `/mybots` → выбери бота.
2. **Bot Settings → Group Privacy → Turn off**.

Дальше:
1. Добавь бота в нужный групповой чат.
2. Администратор чата пишет `/start` (или `/setup`) — появится то же меню,
   что и в личке.
3. Настраивать (группу, семестры, расписание, время рассылки) может
   **только администратор чата в Telegram** — бот сам проверяет права через
   Telegram API. Остальные участники могут пользоваться кнопками
   «на сегодня/на завтра».
4. Рассылка в чат идёт по времени, которое задаст администратор — один раз
   в день на весь чат.

## 5. Админ-панель бота

Команда `/admin` в личном чате (доступна только тем, чей `telegram_id`
указан в переменной `ADMIN_TELEGRAM_IDS`) открывает:

- Редактирование текстов бота — приветствие в личке, приветствие в
  групповом чате, текст `/help`. Список задан в `lib/texts.js`.
- **«📚 Группы и расписание»** — управление ЛЮБОЙ учебной группой (не только
  той, что настроена лично у админа): создание, переименование, удаление
  групп, а также добавление семестров и заполнение расписания для любой из
  них — без необходимости переключать свою личную группу туда-сюда.

Если что-то в боте отвечает не тем, чем должно (тихо "зависает" или ничего
не открывает) — теперь любая необработанная ошибка ловится централизованно:
пользователь получит сообщение «⚠️ Что-то пошло не так», а полный текст
ошибки попадёт в Logs на Vercel — это самый быстрый способ найти причину.

## 6. Развёртывание с нуля

### Шаг 1. Создать бота
В Telegram у `@BotFather`: `/newbot` → получить `BOT_TOKEN`. Заодно сразу
отключи Group Privacy (см. раздел 4), если планируешь использовать бота в
групповых чатах.

### Шаг 2. Создать базу данных
Зарегистрироваться на [neon.tech](https://neon.tech) (бесплатный Postgres),
создать проект, скопировать `DATABASE_URL` (со `?sslmode=require`).

### Шаг 3. Установить зависимости и применить миграции
```bash
npm install
$env:DATABASE_URL="postgresql://..."
npm run migrate
```
(в Windows PowerShell переменные задаются через `$env:ИМЯ="значение"`,
отдельной командой перед основной — так, как показано выше)

### Шаг 4. Задеплоить на Vercel
```bash
npm i -g vercel
vercel
```
В настройках проекта на vercel.com → **Settings → Environment Variables**
добавить:
- `BOT_TOKEN`
- `DATABASE_URL`
- `WEBHOOK_SECRET` (придумай случайную строку)
- `CRON_SECRET` (ещё одна случайная строка)
- `DEFAULT_TIMEZONE` (например `Europe/Moscow`)
- `ADMIN_TELEGRAM_IDS` (твой telegram_id, чтобы был доступ к `/admin`; узнать его можно у бота `@userinfobot`)

Передеплой: `vercel --prod`.

### Шаг 5. Подключить вебхук
```bash
$env:BOT_TOKEN="..."
$env:WEBHOOK_SECRET="..."
node scripts/set-webhook.js https://твой-проект.vercel.app
```

### Шаг 6. Настроить внешний "будильник" для рассылок
На [cron-job.org](https://cron-job.org) (бесплатно) создать job:
- URL: `https://твой-проект.vercel.app/api/tick`
- Метод: GET
- Периодичность: каждую минуту
- Заголовок: `X-Cron-Secret: <значение CRON_SECRET>`

Готово — бот работает.

## 7. Если бот уже был развёрнут раньше (обновление)

### Обновление «расписание с сайта ssaa.ru» (миграция 006)

**Сначала миграция, потом деплой** — новый код использует новые колонки:
```bash
$env:DATABASE_URL="твоя_строка_подключения"
npm run migrate
vercel --prod
```
Миграция ничего не удаляет: старые группы и расписания остаются как были,
заодно исправляется время вида `8:30` → `08:30` (из-за него пары
сортировались не по порядку).

Что ещё исправлено в этом обновлении:
- список преподавателей больше не дублирует людей («Иванова А.И.» и
  «Иванова Анна Ивановна» — один человек) и не склеивает двух
  преподавателей подгрупп в одну кнопку;
- рассылка не теряется, если cron-job.org пропустил минуту (окно 20 минут),
  и не приходит дважды, если два вызова пришли одновременно;
- рассылка на 00:xx теперь срабатывает (раньше Node отдавал время "24:xx");
- длинное расписание семестра делится на несколько сообщений (лимит
  Telegram — 4096 символов) вместо ошибки;
- названия групп и семестров с символами `<`, `>`, `&` больше не ломают
  сообщения.

Проверка без базы и интернета: `npm test`.

### Предыдущее обновление (семестры)

Эта версия добавила семестры с чередованием недель, работу в групповых
чатах, кнопки «на сегодня/на завтра», промпт для нейросети, и **исправила
рассылку по расписанию** (была сломана после введения семестров — код
рассылки не знал о новой структуре данных, теперь оба места используют
общий модуль `lib/digest.js`, так что это не может разъехаться снова).

Если база уже создана — примени новые миграции (скрипт применяет только то,
чего не хватает, старые данные не трогает):
```bash
$env:DATABASE_URL="твоя_строка_подключения"
npm run migrate
```
И передеплой:
```bash
vercel --prod
```
Если хочешь пользоваться групповыми чатами — не забудь отключить Group
Privacy у бота (раздел 4).

## 9. Что можно добавить дальше

- **Права редактирования группы.** Сейчас расписание учебной группы (не
  путать с групповым чатом) может менять любой, кто на неё подписан —
  стоит добавить роль "старосты" с исключительным правом редактирования.
- **Уведомление об изменениях** — если расписание группы поменялось,
  разослать всем подписчикам сообщение "расписание обновлено".
- **Уведомление об изменениях на сайте** — при автообновлении сравнивать
  новое расписание со старым и присылать «📢 завтра изменилось: …».
- **Расписание преподавателя целиком** — сейчас поиск идёт по группам, которые
